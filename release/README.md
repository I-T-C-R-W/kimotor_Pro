# Release Tree

This directory contains the source tree used to build the installable `KMotor_Pro` package.

## Folder

- `com_github_itcrw_kmotor_pro/`

This folder is the plugin source for the package build.
The final KiCad install ZIP is generated by the script and uses PCM layout:

- `metadata.json`
- `plugins/...`
- `resources/icon.png`

## Build

Run:

```bash
./scripts/build_kmotor_pro_release.sh
```

This creates:

- `dist/KMotor_Pro-v<version>.zip`

The ZIP contains only the PCM-compatible package structure, not the full development workspace.
